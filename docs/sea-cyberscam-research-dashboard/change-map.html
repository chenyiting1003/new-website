如何解释这些图层与年份？

“前置→涉诈时间链”要求用途或牌照背景的日期区间严格早于首次涉诈报告。本年只表示证据的日期精度，不等于确证违法开始的时点；区间重叠不会自动判为先后变化。一般建设、停业和搬迁独立显示。曾有报告的地点不代表今天仍在运营。

报道统计使用发表时间，并按相同网址／相同正文去重。“媒体数”指不同来源名称，转载与同一新闻集团尚未全部识别。描述词计数反映检索线索，不能作为残忍或危害程度分数。上下文候选默认关闭，无法匹配的材料保留在研究包的明细数据库。

赌场参考与图片层是当前资料快照，不随年份推断历史状态。赌场清单匹配不等于有效牌照；仅距离接近的候选单独标识。OCR、图片说明和 EXIF 不能独立确认旧用途或封闭化改造。

本页代码与总体统计通过 GitHub 发布。详细研究包在浏览器内读取；底图只向 OpenStreetMap 请求地图瓦片。
