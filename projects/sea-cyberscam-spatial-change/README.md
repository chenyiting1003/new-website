# Southeast Asia Cyber-scam Spatial Change — public dashboard

This directory is the presentation layer for the research project. It contains
only static dashboard files and aggregate, non-record-level summaries.

## Included

- `docs/sea-cyberscam-research-dashboard/` — static research dashboard and local-data change map in the repository root.
- `summary/research_summary.json` — aggregate collection and text-extraction
  counts used for project reporting.

## Not included

Raw HTML, images, place-level CSV/JSON, coordinates, evidence sentences, news
records, scraper logs, extraction rules and research scripts are intentionally
kept outside the `new-website` repository in the local research workspace.

The aggregate numbers describe pipeline output and do not establish that any
individual place underwent a legal-to-illicit transition.
