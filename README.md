# AI治理知识数据库 · Governance

## 简介

**AI治理知识数据库 · Governance** 是一个持续更新、证据可追溯、面向研究复用的AI治理知识基础设施。项目系统收集和组织全球人工智能治理相关的政策文件、法律法规、技术标准、国际合作事件、学术文献、研究机构报告与社会媒体动态，形成具有时间连续性、主体关联性和空间可比较性的结构化数据库。

周报、笔记、标签、引用导出和审核功能仍然保留，但它们将作为人工核验、评论笔记和研究管理流程的一部分。项目的长期目标是建立一个能够支持政策比较、关系网络构建、时间序列分析、知识综述和研究成果可视化的综合性AI治理数据库。

## 目标

数据库围绕“政策—主体—事件—关系—研究—证据”六类核心对象组织信息，重点实现以下目标：

1. 系统保存不同国家、地区和国际组织发布的AI法律、政策、战略、标准、指南、咨询文件、实施措施与执法动态；
2. 持续收录AI治理、国际竞争与合作、研发伦理、风险评估、技术标准、算力、数据和供应链等领域的学术文献与机构研究；
3. 记录国家、国际组织、监管机构、科研机构、企业和多边机制之间的合作、竞争、规则引用、制度借鉴、共同签署与成员关系；
4. 通过定期监控政策、学术研究和社会媒体动态，建立时间连续、来源明确、可以追溯版本变化的治理事件序列；
5. 将检索结果先写入待审核区，经人工核验、修改和批准后再转化为正式知识记录；
6. 为后续的统计分析、网络分析、政策文本分析、时空比较和可视化研究提供标准化数据基础。

## 数据范围

数据库计划覆盖以下主要资料类型：

* 国家和地区发布的AI法律、行政法规、国家战略、监管规则、技术标准和政府指南；
* 联合国、OECD、G7、G20、欧洲委员会、东盟、非洲联盟及其他国际机制发布的原则、协定、报告和会议成果；
* AI国际合作、政策竞争、标准协调、技术转移、跨境数据治理、算力和半导体供应链相关事件；
* AI研发全生命周期中的伦理审查、风险分类、影响评估、模型测试、审计、事故报告和持续监测机制；
* 同行评审论文、学术著作、工作论文、科研机构报告和智库研究；
* 与AI治理议程、政策争论和社会影响相关的新闻及社会媒体材料。

不同来源在数据库中必须明确区分。政府文件、国际组织材料、学术研究、机构观点、新闻报道和社会媒体内容不能被视为同等性质的证据。

## 持续更新机制

数据库通过定期检索形成连续的AI治理时间序列。每周监控主要包括：

* 新发布的政策、法律、标准和指南；
* 既有文件的修订、通过、生效、实施和执法进展；
* 新出现的国际合作、制度竞争和政策分歧；
* 重要学术论文、研究报告和工作论文；
* 对政策议程、治理争议和社会影响具有研究价值的新闻与社会媒体动态。

同一事件的重复报道将被合并。正式记录需要核对发布日期、事件日期、文件状态、发布机构和一手来源。未经人工审核的检索结果不得直接进入正式数据库。

## 可视化

项目计划将数据库中的结构化信息转化为可交互的研究可视化，包括：

* 全球AI治理历史时间轴；
* 国家与地区治理路径地图；
* 国家、机构和国际机制关系网络；
* 政策扩散与制度借鉴网络；
* 全球合作、竞争和政策分歧图谱；
* 不同主题和司法辖区的政策变化趋势；
* 学术研究主题演化；
* 国家治理路径和制度结构比较；
* 中国在全球AI治理与产业网络中的位势变化。

可视化仅用于呈现关系、变化和证据，便于使用者调用。

## 数据与知识组织原则

### 证据优先

优先保存政府、监管机构、国际组织、标准机构、出版社和期刊提供的一手来源。新闻和社会媒体可以用于发现线索、观察争议和分析话语，但不能替代正式政策文件或学术来源。

### 人工审核

自动检索和信息抽取只能生成候选记录。正式数据必须经过人工核验，确认标题、机构、日期、文件状态、来源和主题分类后才能发布。

### 单一事实来源

同一政策、论文、报告或事件只保留一个规范主记录。首页、国家页、周报、研究库和关系网络应引用同一记录ID，避免形成互不一致的重复数据。

### 区分事实与分析

数据库必须分别保存：

* 可由来源直接证明的事实；
* 政府或机构的政策立场；
* 学术研究结论；
* 数据库维护者的分析性判断；
* 尚待验证的关系和推断。

分析性结论不能被写入事实字段。

### 时间与版本可追溯

政策记录应区分发布日期、通过日期、生效日期、修订日期和事件日期。对于多版本框架，应保留版本关系和变化记录，不能将不同版本简单覆盖或全部视为独立政策。

### 可复用与可导出

数据结构应支持CSV、BibTeX、Json及后续研究格式导出，保证政策文本分析、统计建模、关系网络分析和可视化可以在网站之外重复开展。

## 长期愿景

AI治理知识数据库 · Governance 的长期目标是形成一个可持续积累、可人工校验、可用于比较研究和计算分析的开放式知识框架。

随着政策、学术研究和社会讨论持续进入数据库，项目将逐步形成横跨时间、国家、机构、政策和知识主题的AI治理证据网络，为全球AI竞合格局、产业链重构、研发伦理治理、政策扩散和治理知识生产等研究提供连续、透明和可复用的数据基础。
